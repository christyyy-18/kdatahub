📊 Website Summary

Project: K-DATAHUB

Type: Django Web Application

Capture Date: May 30, 2026

🎯 Project Overview

K-DATAHUB is a modern Django web application that facilitates the purchase of telecom data plans (MTN, Airtel, and Telecel) with competitive pricing and fast delivery.

📋 Pages & Features

Homepage

Entry point with service overview and navigation

Authentication

Login and signup pages for user account management

Agent Registration

Special registration page with Paystack payment integration (₵25 fee)

Customer Support

Multi-channel support (WhatsApp, Email, Phone) with FAQ

🔧 Technical Stack

  • Backend: Django 5.0.2 (Python web framework)
  • Database: SQLite3 (db.sqlite3)
  • Payment Integration: Paystack
  • SMS Notifications: SMS service for payment confirmations
  • Frontend: HTML/CSS/JavaScript with responsive design
  • Deployment: Ready for Vercel deployment

💡 Key Features

  • Secure user authentication and authorization
  • Agent registration system with payment gateway
  • Order management and tracking
  • Real-time SMS notifications for transaction updates
  • Multi-network support (MTN, Airtel, Telecel)
  • Responsive design for mobile and desktop
  • Admin dashboard for order management

📂 Project Structure

K-DATAHUB/
├── accounts/           # User authentication and profiles
├── orders/             # Order management system
├── payments/           # Payment processing (Paystack)
├── kdatahub/          # Main project configuration
├── static/            # CSS, JS, images
├── templates/         # HTML templates
├── media/             # User uploads (profile pictures)
├── db.sqlite3         # SQLite database
├── manage.py          # Django management
└── requirements.txt   # Python dependencies

🌍 Deployment Status

  • Development server running on http://localhost:8000
  • Production-ready configuration available
  • Vercel deployment configuration (vercel.json) present
  • Environment variables configured

🔐 Security Features

  • CSRF protection on all forms
  • Secure payment processing via Paystack (PCI-DSS Level 1)
